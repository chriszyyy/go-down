# 六边形平衡消除游戏 - 完整设计文档（基于Prefab架构）

## 1. 游戏简介

此游戏是一款通过点击消除方块，让顶部六边形球在重力作用下逐层下落，同时保持平衡不掉落的物理益智游戏。目标是在不让六边形掉出塔外的前提下尽可能让其下落更多层数。

**核心架构**：采用Prefab-based设计，所有方块和六边形球均为预制体，通过智能算法动态拼装塔结构。方块支持旋转以实现最优布局。

## 8. Unity 技术实现（Prefab架构）

### 8.1 Prefab系统

**方块Prefab（6种）**：
- SingleBlock (1x1) - 单格方块
- SquareBlock (2x2) - 正方形方块
- L3Block (2x3) - L型3格
- L4Block (2x4) - L型4格
- L5Block (3x3) - 等长L型5格
- LineBlock (4x1) - I型横条

**六边形球Prefab**：
- 直径2.0单位（等于2个方格宽度）
- PolygonCollider2D (6个顶点)
- Dynamic Rigidbody2D
- HexagonBall脚本控制

### 8.2 统一标准

- **尺寸标准**：1单位 = 1格
- **Pixels Per Unit**：64 (方块) / 128 (六边形球)
- **碰撞器间隙**：0.95倍Sprite大小，留出视觉间隙
- **Layer系统**：Block层、HexagonBall层、Boundary层
- **物理参数**：Continuous碰撞检测、Kinematic静态方块

### 8.3 TowerBuilder算法（核心）

**智能拼装系统**：
```
TowerBuilder.BuildTower():
1. 从底层开始，逐层填充
2. 每层宽度固定（如8个单位）
3. 随机选择Prefab组合填充
4. 支持方块旋转以优化布局
5. 检测是否填满一层，未满则继续选择

关键特性：
- 旋转算法：尝试0°/90°/180°/270°找到最佳放置角度
- 宽度适配：根据剩余空间选择合适的Prefab
- 间隙最小化：优先选择能完美填充的组合
- 对称性：可选的左右对称布局提升稳定性
```

**动态物理切换**：
```
初始状态：所有方块 Kinematic (静止)
点击消除方块后：
1. 触发TowerBlock.DestroyBlock()
2. 上层方块检测支撑消失
3. 自动切换为Dynamic (启用重力)
4. 下落并与新层碰撞
5. 稳定后冻结为Kinematic
```

### 8.4 TowerBlock基类

所有方块继承自TowerBlock：
- `OnMouseDown()` - 点击检测
- `DestroyBlock()` - 消除动画
- `MakeDynamic()` / `Freeze()` - 物理状态切换
- `OnBlockDestroyed` - 静态事件通知
- `scoreValue` - 得分值
