# 六边形平衡消除游戏 - 完整设计文档（Markdown 版）

## 1. 游戏简介

此游戏是一款通过点击消除方块，让顶部六边形球在重力作用下逐层下落，同时保持平衡不掉落的物理益智游戏。目标是在不让六边形掉出塔外的前提下尽可能让其下落更多层数。

## 3. 游戏系统说明（按照架构图）

### \### 3.1 Core Game Layer

-   **Gameplay Controller**\
    控制整体流程（消除→下落→判定→得分）。
-   **Block Manager**\
    管理方块生成、结构排列、消除逻辑。
-   **Hexagon Ball Manager**\
    管理六边形物理、旋转、倾斜、掉落检测。
-   **Level Generator**\
    生成固定或随机关卡结构。
-   **Physics Engine (2D)**\
    处理重力、碰撞、摩擦、稳定状态检测。

## 4. 玩法设计（核心逻辑）

### 4.1 操作方式

-   点击方块 → 方块消除\
-   上层结构受重力下落\
-   六边形可能发生倾斜\
-   不要让球掉出结构外

### 4.2 得分方式

-   下落层数分\
-   完美平衡奖励\
-   连续点击 Combo 加成

### 4.3 失败判定

-   球中心点越界\
-   球角度超过安全区\
-   球速度过快导致飞出

## 8. Unity 技术实现（概要）

### 方块

-   BoxCollider2D（Static）\
-   消除=禁用物体\
-   上层方块转为 Dynamic 下落再冻结

### 六边形球

-   PolygonCollider2D + Rigidbody2D\
-   AngularDrag 调整控制\
-   使用外包围框检测掉落
